# Portfolio Supabase backend

This directory documents the database used by the public portfolio and `/admin/` workspace.

- Project: `raihan-portfolio`
- Region: Singapore (`ap-southeast-1`)
- Authorized admin: `mdaminulhoqueraihan@gmail.com`
- Public browser access uses only the Supabase publishable key.
- Content writes, inquiry reads and media writes require an authenticated authorized admin.
- Public visitors may read published portfolio content and insert contact submissions only.

`schema.sql` is the reproducible schema. Never add the service-role key to this repository.
